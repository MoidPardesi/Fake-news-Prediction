****Fake News Detection ****

**Overview**
This repository showcases the machine learning models and framework developed focused on detecting fake and real news using AI. The final models are implemented in Python and hosted on a web app to make the research accessible for public use.

**Project Description**
The research involved a thorough literature review and application of various machine learning algorithms to automate fake news detection. The primary goal was to provide a tool that the public could use to verify news authenticity in real-time.

**Key Features**
Machine Learning Models: Logistic Regression, Random Forest, SVM, Naïve Bayes, and k-Nearest Neighbors.
High Accuracy: Achieved accuracy rates up to 97.35% with Logistic Regression, demonstrating excellent real-world applicability.
Web Application: Developed a practical web application for real-time news verification, contributing to the fight against misinformation. Access the application here: "https://fakenewspredict.streamlit.app/"

**Impact**
Real-Time Detection: Enables users to check the authenticity of news articles instantly, aiding in informed decision-making and promoting societal cohesion.
Educational Value: Provides insights into machine learning applications in media, enhancing transparency and trust in digital content.

**Model Performance**
Best Performing Model: Logistic Regression with an accuracy of 97.35%.
Strong Alternatives: SVM and Random Forest also showed robust performance, offering reliable options for different operational contexts.

**Conclusion**
The research affirmed the potential of machine learning in real-time fake news detection, which can play a crucial role in mitigating political instability and misinformation spread. Future work will focus on enhancing model adaptability and addressing potential biases.
